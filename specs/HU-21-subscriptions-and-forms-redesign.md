# HU-21: Redesign subscriptions and forms

- **Status:** Implemented _(2026-10-15)_
- **Epic:** EP-01 · **Priority:** P1 · **Dependencies:** HU-16, HU-17, HU-18

## Goal

Make the subscription list, create form and edit form clearer on desktop and mobile without changing
their existing behavior.

## Acceptance criteria

- Desktop rows prioritize name, amount, status and next billing date.
- Mobile subscriptions render as readable cards without horizontal scrolling.
- Upcoming and overdue charges receive meaningful visual treatments.
- Search continues to filter the current subscription list.
- Create and edit fields remain accessible and visually grouped.
- Backend validation errors remain visible and actionable.
- Usage, edit and delete actions continue to work.
- The empty state encourages adding the first subscription.
